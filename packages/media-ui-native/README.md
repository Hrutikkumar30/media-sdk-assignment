# @my-app/media-ui-native

React Native UI components for building media galleries.

## Features

- **Independent**: No dependencies on business logic or API clients. Just React Native.
- **Components**:
  - `Grid`: A flatlist wrapper for easy grid layouts.
  - `Lightbox`: A simple, accessible image viewer modal.
  - `ReelSwiper`: A full-screen vertical swiper for reels/shorts-style content.

## Installation

```bash
npm install @my-app/media-ui-native
```

## Usage

See `examples/` for usage of `Grid`, `Lightbox`, and `ReelSwiper`.
